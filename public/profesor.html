Enlaces para el tutor (WhatsApp)

PISAC elige automáticamente la mejor dirección disponible para los enlaces del reporte.

Solo hace falta si quieres que el enlace funcione fuera de tu red (datos móviles u otra red). Para una demo puedes usar un túnel gratuito:
cloudflared tunnel --url http://localhost:3000
y pegar aquí la dirección https://algo.trycloudflare.com.

Cómo se envía el mensaje

PISAC no envía mensajes por sí sola: abre WhatsApp con el mensaje y el enlace ya escritos, y tú solo pulsas enviar. Así funciona con cualquier número y sin costo.

  1. Registra al estudiante con el teléfono del tutor incluyendo el código de país (+593…).
  2. En Notificaciones elige el estudiante y pulsa Generar enlace y notificar.
  3. Pulsa Enviar por WhatsApp: se abre WhatsApp con el mensaje listo.
  4. Pulsa enviar dentro de WhatsApp. El tutor recibe el texto y el enlace del reporte.
